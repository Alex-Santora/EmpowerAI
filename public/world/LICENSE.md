# World data attribution

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

`boston-layout.json` is a filtered, simplified and locally projected derivative of
OpenStreetMap data, made available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
The source attribution, source SHA-256, extraction bounds, projection and OSM
snapshot timestamp are embedded in the file. The accompanying development
script in `scripts/generate-boston-world.py` documents how to reproduce it.

`district-poster.webp` is a rendered produced work of this data with the original
FutureWithAI architectural interpretation. It carries the same OSM attribution
through the Mission footer. Neither file contains Google Maps data or imagery.

The commissioned architecture is original and is not a model of Boston's
historical or contemporary landmark buildings. No source street names are used.
